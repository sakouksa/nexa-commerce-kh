# Nexa Commerce KH — Mobile POS App (`nckhposapp`)

Flutter Point-of-Sale (POS) mobile application for **Nexa Commerce KH** merchants and cashiers.

## Features
- Fast product catalog browsing and instant search
- Dual currency display (USD and Khmer Riel KHR with live exchange rate)
- One-tap cart additions & quantity increment/decrement
- Cash and Bakong KHQR checkout flows
- Integration with Laravel 13 Core API (`backend/nckhcoreapi`)

## Running the App
```bash
flutter pub get
flutter run
```
